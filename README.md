# 📋 Sistema de Encuesta de Retroalimentación

## Descripción

Aplicación desarrollada en Java utilizando Java Swing para registrar encuestas de satisfacción de clientes.

El sistema permite ingresar comentarios, seleccionar categorías, evaluar el servicio, destacar aspectos relevantes y generar un informe con la información registrada.

## Tecnologías

- Java
- Java Swing
- Eclipse IDE
- Programación Orientada a Objetos

## Funcionalidades

- Registro de comentarios.
- Selección de categoría.
- Calificación del servicio.
- Selección de aspectos destacados.
- Generación de informe.
- Limpieza del formulario.
